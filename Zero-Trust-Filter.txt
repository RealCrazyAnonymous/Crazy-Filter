! Title: Zero Trust Filter
! Description: A DNS-level blocklist that blocks ads, trackers, phishing, malware, and scams by filtering domain name resolutions. Compatible with Pi-hole, AdGuard Home, Blocky, and other DNS sinkholes. Operates purely at the DNS layer—it does NOT modify routing tables, interfere with Wi-Fi connectivity, alter firewall rules, block IP addresses, or affect network hardware. It simply returns null results for blocked domains. Safe for home, enterprise, and VPN environments.

! Compatibility Below

! This filter is compatible with:

! Pi-hole

! AdGuard Home

! Blocky

! Technitium DNS Server

! pfBlockerNG

! NextDNS / Control D

! Any DNS sinkhole that supports standard domain lists
